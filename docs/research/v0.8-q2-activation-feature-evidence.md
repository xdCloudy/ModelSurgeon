# v0.8 Q2 activation-feature evidence

## Result

Adding six calibration-derived activation summaries to the 19 static weight
features did not produce a statistically resolved predictive gain in this bounded
three-model study. Every paired 95% interval for AUC and regression error reduction
includes zero. Point estimates vary in sign, including a sizeable held-out decline
for SmolLM2-135M, so the evidence does not support enabling these activation
features by default yet.

Positive AUC/precision values and positive MAE/RMSE reductions favor
static-plus-activation.

| Target | AUC gain (95% paired CI) | Precision@10 gain (95% paired CI) | MAE reduction (95% paired CI) | RMSE reduction (95% paired CI) |
| --- | ---: | ---: | ---: | ---: |
| SmolLM2-135M | -0.104 (-0.244–0.028) | -0.300 (-0.600–0.000) | 0.00026 (-0.00260–0.00328) | 0.00161 (-0.00432–0.00754) |
| SmolLM2-360M | 0.061 (-0.117–0.251) | 0.100 (0.000–0.300) | -0.00007 (-0.00021–0.00008) | -0.00004 (-0.00017–0.00009) |
| Qwen2.5-0.5B | -0.046 (-0.210–0.100) | -0.100 (-0.300–0.200) | 0.00001 (-0.00056–0.00060) | 0.00015 (-0.00039–0.00090) |

The corresponding AUC changes were 0.517→0.413, 0.556→0.616, and
0.520→0.473. Precision@10 changed 0.600→0.300, 0.800→0.900, and
0.800→0.700. The complete absolute metrics and their individual grouped intervals
are retained in the machine-readable report.

## Paired protocol

- Q2 reuses the exact 1,536 real Q1 mutation examples, target revisions, safe
  threshold (ΔPPL <= 0.01), component-held-out assignments, seeds, and 512-example
  per-model budgets. It does not rerun or resample mutations.
- The static model sees the 19 null-`sample_context` weight summaries. Its paired
  model sees those same fields plus `activation_mean`, `activation_abs_mean`,
  `activation_rms`, `activation_std`, `activation_zero_fraction`, and
  `activation_max_abs` captured from the same 64-token calibration forward.
- Both profiles independently fit train-only preprocessing and deterministic
  LightGBMs. Test labels, targets, ordering, and group IDs are asserted identical
  before comparison.
- Gain uncertainty uses 1,000 paired grouped-bootstrap repetitions. Whole held-out
  component groups are resampled once and applied to both predictions, preserving
  their correlation.

## Collection cost

Collection cost was measured after model load on the same RTX 3060 system. Static
summaries cover every MLP channel in every layer. Activation overhead compares a
warmed forward with hooks against an otherwise identical warmed no-hook forward;
this avoids charging model load, tokenizer work, or perplexity evaluation itself
to activation features.

| Target | Static collection | No-hook forward | Activation forward | Activation time overhead | Peak RSS overhead | Peak allocated VRAM overhead |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| SmolLM2-135M | 0.172 s | 0.047 s | 0.063 s | 0.016 s | 0.14 MiB | 0 MiB |
| SmolLM2-360M | 0.328 s | 0.047 s | 0.047 s | 0.000 s | 0.25 MiB | 0 MiB |
| Qwen2.5-0.5B | 0.328 s | 0.032 s | 0.047 s | 0.015 s | 0.14 MiB | 0 MiB |

Peak allocated VRAM during the activation forwards was 29.6, 29.6, and 91.6 MiB
above the loaded-model baseline, but the same peaks occurred in their paired
no-hook forwards; the hooks added no observed allocated-VRAM peak. SmolLM2-360M
did add 2 MiB to peak reserved VRAM. These are single-run resource measurements at
the host timer's resolution, not confidence-bounded performance benchmarks.


The null result is specific to one short calibration text, single-channel masks,
three sub-billion-parameter dense models, and 512 candidates per target. It does
not establish that activation features lack value under larger or task-specific
calibration sets.
