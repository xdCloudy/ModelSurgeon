# v0.5 First Surgeon empirical evidence

This report records the first several-thousand-mask empirical run for milestone
`v0.5 — First Surgeon`. The result is intentionally reported even though the
learned classifier did not outperform the simple baselines: milestone completion
means the experiment is reproducible and the declared metrics exist, not that the
initial feature set is already a strong surgeon.

substantially slower and remains an optimization target.

## Dataset and leakage audit

The campaign produced 3,000 independently addressable MLP-channel masks with
static weight and activation features. The component-held-out split and labels
were:

| Partition | Examples/groups | Safe (`delta <= 0`) | Unsafe (`delta > 0`) |
| --- | ---: | ---: | ---: |
| Train | 2,400 | 1,651 | 749 |
| Validation | 300 | 211 | 89 |
| Test | 300 | 209 | 91 |

The leakage audit reported zero findings. Perplexity deltas ranged from
`-1.887447` to `2.012140`, with median `-0.118746`, so every split contained both
classes under the policy fixed before training.

## Identical-candidate baseline comparison

| Ranking | ROC-AUC | PR-AUC | Precision@50 | Recall@50 |
| --- | ---: | ---: | ---: | ---: |
| Learned LightGBM | 0.5104 | 0.7109 | 0.70 | 0.1675 |
| Seeded random | 0.5105 | 0.7115 | 0.64 | 0.1531 |
| Normalized magnitude | 0.5172 | 0.7109 | 0.70 | 0.1675 |

The confidence intervals overlap substantially. This proof therefore does not
support a claim that the first static-plus-activation LightGBM ranks safe masks
better than magnitude or random on this model/calibration sample. It does support
the end-to-end data, training, persistence, inference and evaluation contracts and
provides a concrete baseline for active-learning work in v0.6.

## Validation gate

At the evidence revision, the complete local gate passed with 812 tests passing,
one environment-specific skip, Ruff clean, and strict mypy clean across 146 source
files. Real LightGBM, PyTorch, CUDA cleanup, CPU MLP, CUDA MLP, immutable reload and
CLI train/predict paths were exercised on the test PC.
