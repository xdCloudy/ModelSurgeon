# v0.7 coordinated hidden-dimension study

The bounded study evaluates one-layer Llama and Qwen2 graphs with 256-wide hidden state, eight
query heads, four KV heads, 32-wide key/value heads, Q4_K matrices, and F32 norms.

For both families it maps all global feature-axis consumers and three normalization tensors. The
combined contiguous-axis quantization granularity is 256 hidden features because every affected
Q4_K axis-0 must remain super-block aligned.

Result: **physical hidden-dimension surgery is rejected for both families**. No feasible operation
class is emitted and no mutation implementation is exposed, because rotary/config consumers and
embedding/output tying cannot yet be proven from the physical graph. Tests also require exactly
the two intended families and enforce a caller-supplied tensor-count ceiling.
