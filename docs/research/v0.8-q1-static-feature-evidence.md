# v0.8 Q1 static-feature evidence

## Result

Static weight statistics alone did not reliably discriminate safe channel masks in
this bounded study. Held-out AUC confidence intervals include 0.5 for all three
models and held-out regression R² is approximately zero or negative. The useful
result is therefore a measured baseline for the activation and gradient ablations,
not a claim that static features are sufficient.

| Target | Test safe / unsafe | AUC (95% grouped CI) | Precision@10 (95% grouped CI) | MAE (95% grouped CI) | RMSE (95% grouped CI) |
| --- | ---: | ---: | ---: | ---: | ---: |
| SmolLM2-135M | 27 / 24 | 0.517 (0.345–0.677) | 0.600 (0.300–0.900) | 0.01915 (0.01448–0.02485) | 0.02672 (0.01900–0.03587) |
| SmolLM2-360M | 42 / 9 | 0.556 (0.339–0.763) | 0.800 (0.500–1.000) | 0.01421 (0.01068–0.01853) | 0.02045 (0.01253–0.02780) |
| Qwen2.5-0.5B | 41 / 10 | 0.520 (0.314–0.734) | 0.800 (0.500–1.000) | 0.00666 (0.00499–0.00876) | 0.00978 (0.00650–0.01354) |

Precision must be interpreted with the class balance shown in the table: “safe” is
the positive class and is common in the two larger-model test sets. AUC and the
regression results make the weak static-only signal clearer.

## Frozen protocol

- Targets are the three smallest pinned entries in the v0.8 ladder: two Llama-family
  SmolLM2 checkpoints and the Qwen-family Qwen2.5-0.5B checkpoint.
- Each target uses 512 seeded single-channel MLP masks, giving 1,536 real mutation
  evaluations. Every model has 409 train, 52 validation, and 51 held-out test
  examples under the component-grouped split (seed 43).
- The calibration input is repository `README.md` at SHA-256
  `8c2407dce2b43a57cdc72104d520280486b4c3b2992e5eb25caf8a961550905c`,
  bounded to 64 tokens in one 64-token chunk.
- The safe label is post-minus-baseline perplexity <= 0.01 for every model. This
  common cutoff was fixed after a protocol audit showed the v0.5 cutoff of 0.25
  made all 512 SmolLM2-360M observations safe. No model-specific cutoff was tuned.
- Only the 19 weight-derived features whose persisted `sample_context` is null are
  retained. Six `activation_*` records are removed before preprocessing and model
  fitting. Train-only imputation/scaling and categorical vocabulary rules remain
  unchanged.
- One deterministic LightGBM classifier and regressor are fit per target with seed
  42 and four threads. Uncertainty is a 1,000-repetition 95% grouped bootstrap over
  held-out component groups. Top-N is 10.
- The run used Windows 11, CPython 3.12.13, PyTorch 2.13.0+cu130, an RTX 3060 12 GB
  (driver 610.74), and 64 GB system RAM. Summed persisted candidate evaluation time
  was 11.691 s, 13.093 s, and 11.112 s respectively; download/load/training time is
  not included in those candidate timings.

## Reproduction and integrity

The canonical machine-readable report is
[`v0.8-q1-static-study.json`](v0.8-q1-static-study.json), SHA-256
`22c8a0f14068a7792a7756a0bd5612d904eaaa73b0859f1de0d4775b0744bd7e`.
It contains all metric estimates, confidence bounds, immutable model revisions,
feature names, counts, and source hashes. Model weights and the larger JSONL
datasets remain outside Git.

```text
python tools/run_q1_static_study.py \
  --dataset ../proof-v08-q1-smollm2-135m-512 \
  --dataset ../proof-v08-q1-smollm2-360m-512 \
  --dataset ../proof-v08-q1-qwen25-05b-512 \
  --output docs/research/v0.8-q1-static-study.json \
  --safe-perplexity-delta 0.01 --top-n 10 --bootstrap-repetitions 1000
```
