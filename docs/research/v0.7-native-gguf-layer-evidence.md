# v0.7 native GGUF layer-removal evidence

A deterministic three-layer Llama GGUF fixture uses Q4_K encoded matrices and F32 normalization
tensors. Removing the middle block produces this canonical mapping:

`0 → 0, 1 → removed, 2 → 1`

The end-to-end Windows proof verifies:

- `llama.block_count` changes from 3 to 2.
- Every `blk.1.*` source tensor is omitted.
- Every `blk.2.*` source payload reappears byte-identically under `blk.1.*`.
- Global and original block-0 payloads remain byte-identical.
- No output tensor references block 2, and rediscovery builds a consistent two-layer graph.
- The source GGUF SHA-256 is unchanged.
- Peak payload copying remains within the configured 4,096-byte chunk ceiling.

An additional fail-closed test rejects removal of every transformer layer during planning.
