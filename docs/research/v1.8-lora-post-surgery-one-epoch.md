# v1.8 post-surgery LoRA: one-epoch, three-seed study

## Result

The prior 64-row experiment selected its final checkpoint at step 16 for all
three seeds, after using only the first 16 of 64 repair rows. This follow-up
allowed 64 updates: one deterministic pass through the same 64-row training
split. The validation set was evaluated after each update with token-weighted
causal-target loss. The pinned source, prune selection, data rows, test set,
precision, LoRA rank, and learning rate were otherwise unchanged.

| Arm | Mean test token loss | Mean test perplexity | Full artifact bytes |
| --- | ---: | ---: | ---: |
| Source FP16 | 3.51242 | 33.52926 | 272,437,465 |
| Pruned, no repair | 3.75717 | 42.82719 | 265,801,794 |
| Pruned, LoRA, mean of seeds | 3.53173 | 34.18307 | 265,801,794 |

| LoRA seed | Test mean token loss | Loss recovered vs. no repair | Validation loss, step 0 → step 64 |
| ---: | ---: | ---: | ---: |
| 42 | 3.53327 | 0.22391 | 3.41664 → 3.17107 |
| 43 | 3.53029 | 0.22688 | 3.41664 → 3.16764 |
| 44 | 3.53163 | 0.22554 | 3.41664 → 3.17082 |

Mean recovery was 0.22544 nats (sample standard deviation 0.00149) across adapter
seeds. Relative to the 0.24475-nat degradation from pruning, this recovered
about 92% on these fixed test rows. The repaired models remained 0.01931 nats
worse than source. Every seed selected step 64, and validation loss decreased
at every recorded update. Thus one pass substantially improved the result over
the 16-update budget, but the optimum duration and later overfitting behavior
remain unknown.

The physically pruned FP16 artifacts remained 2.44% smaller than source. Repair
trained 122,880 parameters for 190–223 seconds per seed and used 778,641,920
peak allocated CUDA bytes on the RTX 3060. These data do not establish an
inference-speed improvement.

This comparison uses one model, one fixed 64-row selection per split, one
pruning severity, and three adapter initialization seeds. The seeds do not
represent independent test sets. Treat the near-source score as bounded
feasibility evidence, not proof of quality equivalence, broad generalization,
or a competitive quality–compression frontier.
