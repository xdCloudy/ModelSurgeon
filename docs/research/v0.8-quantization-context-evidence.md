# v0.8 quantization-aware surgeon context evidence

## Result

ModelSurgeon now encodes codec, effective bits per weight, feature error estimates,
source precision, model scale, and hardware context as source-only training inputs.
A paired ablation over the three Q3 campaigns found exactly zero predictive change:
all context-aware and context-blind predictions and metrics are identical.

| Model | Blind / aware AUC | Blind / aware MAE | AUC gain | precision@10 gain | MAE reduction | RMSE reduction |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| SmolLM2-135M | 0.84877 / 0.84877 | 0.01227 / 0.01227 | 0 | 0 | 0 | 0 |
| SmolLM2-360M | 0.95238 / 0.95238 | 0.00863 / 0.00863 | 0 | 0 | 0 | 0 |
| Qwen2.5-0.5B | 0.86341 / 0.86341 | 0.00458 / 0.00458 | 0 | 0 | 0 | 0 |

This is expected rather than evidence that context is useless. Every row within a
campaign is float16 high precision, runs on the same RTX 3060/Windows host, and has
the same model identity and parameter count. Tree models cannot use a feature that
does not vary inside their training split. The ablation therefore quantifies the
context value as zero under the current single-environment protocol and exposes the
need for the matched multi-codec outcomes in the next study.

## Input contract

The leakage-safe training matrix now derives the following fields exclusively from
the pre-mutation model, feature precision, and hardware records:

- categorical: exact model codec/recipe, feature source precision, accelerator
  identity, operating system;
- numeric: codec layout bits per weight, mean and maximum empirical feature error,
  model parameter count, CPU logical cores, system memory, accelerator memory;
- existing family, format, mutation kind, and candidate scope remain unchanged.

Q4_K_M/Q4_K_S and Q5_K_M/Q5_K_S resolve to their concrete Q4_K/Q5_K layout for
bits-per-weight calculation while retaining the exact recipe category. Unknown
codecs and missing hardware remain explicit unknown/missing values rather than
guessed defaults. Inference recomputes the same context and uses train-fitted
scaling and categorical vocabularies.

A focused contract test trains on otherwise identical BF16 and Q4_K_M examples.
Their transformed rows differ in both codec category and bits per weight, and a
fitted regression surgeon returns different predictions. Thus the implementation
can condition decisions on source precision even though the current real campaigns
contain no within-model codec variation.

## Ablation protocol

- Both arms use identical Q3 static-plus-activation-plus-gradient features,
  409/52/51 splits, ΔPPL <= 0.01 labels, seed 42, and 1,000 paired grouped bootstrap
  repetitions.
- The blind arm excludes all new context categories and numeric fields before
  fitting preprocessing. The aware arm includes them. Targets and held-out row order
  are asserted identical, so no target-derived field enters either input.
- The aware real campaigns expose model parameter count, 16 bits/weight, 20 logical
  CPU cores, 64 GiB system memory, RTX 3060 identity, and 12 GiB VRAM. Error fields
  are correctly missing because their Q3 features are marked high precision.

## Validity boundary

The ablation cannot estimate codec or hardware interaction without matched outcomes
that vary those fields. Counterfactually relabeling duplicated high-precision rows
would create a positive result by construction and was deliberately avoided. The
next surgery-versus-requantization study supplies real codec variation; broader
hardware value requires campaigns collected on additional devices. Context fields
enable conditional predictions but do not themselves guarantee calibration under
an unseen codec or host.
