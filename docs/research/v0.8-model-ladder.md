# v0.8 permissive multi-family model ladder

## Selection contract

Issue #163 defines the finite model set used by later cross-model, cross-family,
quantization, and scale studies. Every target is public, ungated, Apache-2.0,
and pinned to a full Hub commit. Metadata was verified through the Hugging Face
Hub API on 2026-08-24. The canonical ladder ID is
`dcb64f73295bcba8af2999e3e2bd5cdc189f48a2b5ce99962d22c3f92f94edb0`.

No model weights belong in Git. The repository ignores `.safetensors`, `.gguf`,
and `.bin` payloads; downstream runners must resolve these identifiers into an
external cache or artifact directory.

The “3B” rung uses a 4.02B model, within the declared ±40/35% rung tolerance,
because Qwen2.5-3B reports a non-permissive `other` license. The ladder rejects
that otherwise closer size rather than weakening its license rule.

Gemma is intentionally absent: its available weights use the Gemma terms rather
than one of this ladder's accepted permissive SPDX licenses. Gemma remains in the
synthetic architecture and GGUF compatibility suites, but no Gemma weight target
is mislabeled as permissive.

## Dataset and hardware compatibility

Every rung supports the local `modelsurgeon-smoke-v1` causal-text protocol and
the `wikitext-2-raw-v1:test` perplexity protocol. This describes tokenizer/text
compatibility, not a promise that every full-scale run fits every machine.

Small targets retain CPU-smoke modes. The 1B and 1.5B rungs introduce bounded CPU
streaming. The 3B and 7B endpoints require quantization for the 12 GB class and
retain a 24 GB reference mode. Later scale studies must report actual RAM, VRAM,
disk, timeout, and failure evidence rather than infer feasibility from the label.

## Automated invariants

`tests/test_model_ladder.py` verifies ordered size coverage, full immutable
revisions, permissive licenses, public/ungated access, at least three architecture
families, per-target purposes, hardware and dataset protocols, size tolerances,
canonical serialization, and the stable content-addressed ladder ID.
