# HF gradient streaming model-scale follow-up

This follow-up checks the streamed-gradient memory and score-ranking behavior on the larger cached Qwen2.5-1.5B model using the same pinned WikiText-2 training calibration window as the 0.5B study.

## Protocol

- Model: `Qwen/Qwen2.5-1.5B`, immutable revision `8faed761d45a263340a0528343f099c05c9a4323`.
- Calibration: first 1,024 tokens / eight 128-token chunks from the extracted `Salesforce/wikitext` `wikitext-2-raw-v1` training split; calibration input bytes SHA-256 `dd19e768934268c03ddcf1e880debd6f862dbf23789a83e465f7aa3233ce4170`. The source archive and training member hashes are recorded in [the WikiText-2 dataset follow-up](v1.8-gradient-wikitext-memory-evidence.md).
- Hardware: NVIDIA GeForce RTX 3060 12 GB. Software: Python 3.14.7, PyTorch `2.14.1+cu130`, Transformers 5.10.1. Model weights are fp16; logits are cast to fp32 for cross-entropy.
- Layers: first MLP layer 0 and last MLP layer 27. Each mode ran three paired allocator measurements in alternating order, with gradients enabled for the selected layer's gate/up/down matrices only.
- Raw CUDA counters and all per-run timing and numerical comparison fields: `v1.8-gradient-model-scale-evidence-v1.json`.

## Results

| Layer | Retained incremental peak | Streamed incremental peak | Reduction | Score Spearman | Top 1% / 5% overlap |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 3,029,223,424 B (2.82 GiB) | 700,083,200 B (0.65 GiB) | 76.89% | 0.99999982 | 100% / 100% |
| 27 | 977,586,176 B (0.91 GiB) | 443,550,720 B (0.41 GiB) | 54.63% | 1.0 | 100% / 100% |

The largest absolute peak allocation was about 6.13 GB for the retained layer-0 measurement, below the RTX 3060's 12 GB capacity. The peak reduction varies by depth, consistent with different live activation state around the measured layer.

As in the 0.5B runs, fp16 gradient tensors and first-order score vectors fail the strict `allclose(rtol=1e-4, atol=1e-6)` check. Maximum absolute first-order score differences were `3.14e-6` at layer 0 and `1.84e-5` at layer 27; the top 1% and 5% candidate sets were unchanged in the three paired comparisons per layer.

## Limits

This is evidence for reduced gradient-collection peak allocation on two sizes of one model family on the target consumer GPU. It is not a general memory model, quality measurement, inference performance result, or proof of elementwise gradient equivalence. The experiment covers only two layers, one 1,016-target calibration window, and three repeated allocator measurements per mode; no general speed or model-optimization claim follows.
