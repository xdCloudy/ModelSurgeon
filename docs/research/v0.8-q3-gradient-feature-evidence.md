# v0.8 Q3 gradient-feature evidence

## Result

Eight analytic gradient summaries add a strong held-out component-ranking and
regression signal on all three target models. Unlike Q2, every paired AUC, MAE,
and RMSE gain interval is above zero. Positive values favor the
static-plus-activation-plus-gradient profile.

| Target | AUC gain (95% paired CI) | Precision@10 gain (95% paired CI) | MAE reduction (95% paired CI) | RMSE reduction (95% paired CI) |
| --- | ---: | ---: | ---: | ---: |
| SmolLM2-135M | 0.436 (0.244–0.630) | 0.700 (0.400–1.000) | 0.00662 (0.00265–0.01036) | 0.00915 (0.00424–0.01365) |
| SmolLM2-360M | 0.336 (0.109–0.578) | 0.100 (0.000–0.400) | 0.00565 (0.00322–0.00868) | 0.00890 (0.00362–0.01378) |
| Qwen2.5-0.5B | 0.390 (0.168–0.611) | 0.300 (0.000–0.600) | 0.00207 (0.00079–0.00337) | 0.00326 (0.00139–0.00485) |

Held-out AUC changed 0.413→0.849, 0.616→0.952, and 0.473→0.863.
Regression R² changed 0.113→0.642, -0.004→0.679, and -0.007→0.559.
Precision@10 reached 1.0 on all three gradient runs, although the paired precision
gain interval touches zero on the two larger targets.

## Paired protocol

- Q3 preserves the Q1/Q2 512-example/model mutation budgets, component-held-out
  splits, ΔPPL <= 0.01 safe definition, calibration text, and seeds. Test rows and
  labels are asserted identical between profiles.
- The baseline contains 19 static and six activation fields. The paired model adds
  `gradient_l1_norm`, `gradient_l2_norm`, `gradient_max_magnitude`,
  `weight_gradient_sum`, `weight_gradient_abs_sum`,
  `weight_gradient_l2_norm`, `first_order_removal_estimate`, and
  `first_order_removal_magnitude`.
- One pre-mutation causal-LM backward is run over 63 target tokens. Only requested
  MLP gate/up/down projection parameters require gradients; their original flags
  and all gradients are restored/cleared in a `finally` path.
- For each requested channel, gate row, up row, and down column weight/gradient
  products are summarized without retaining full float64 snapshots. The feature
  represents the coupled structural channel direction, while the empirical label
  remains the reversible channel-mask ΔPPL from Q1.
- Gain uncertainty uses 1,000 paired grouped-bootstrap repetitions over held-out
  component groups. Positive error “reduction” is baseline error minus gradient
  model error.

runs; they do not have confidence intervals.

## Validity boundary

The gradient loss and mutation ΔPPL labels use the same short calibration sequence.
This is not post-mutation label leakage—the gradients are collected once from the
unchanged model before any candidate is evaluated—but it is an intentionally
within-calibration result. It establishes component transfer within three models,
not text-distribution transfer. Q5/Q6 must prevent target-model examples and fitted
preprocessing from crossing model boundaries; a later dataset study should also
hold out calibration text before claiming task-general sensitivity prediction.
