# v0.6 tree-surgeon uncertainty evidence

This bounded study compares seeded ensembles, row-bootstrap ensembles, and quantile
LightGBM intervals for issue #106. It uses validation labels for early stopping, interval
evaluation, and method selection; the held-out test labels are never loaded by the study.

## Validation comparison

| Method | Coverage | Coverage error | Error-rank Spearman | Mean width | CPU seconds | Model bytes |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Seeded subsample ensemble | 0.0533 | 0.8467 | 0.1493 | 0.0377 | 1.234 | 439,929 |
| Row-bootstrap ensemble | 0.1133 | 0.7867 | 0.1889 | 0.0895 | 1.688 | 449,325 |
| Lower/median/upper quantile | 0.8600 | 0.0400 | 0.1975 | 0.8200 | 0.656 | 183,092 |

The documented selection rule chose the quantile method: it was closest to target
coverage, ranked errors slightly better, and also used the least measured CPU and
serialized model storage in this run.

## Interpretation and negative result

The ensemble and bootstrap spreads are severely under-dispersed. They do not provide
credible 90% intervals for this dataset, even though bootstrap uncertainty ranks absolute
errors somewhat better than the seeded ensemble. Downstream acquisition must not describe
these narrow intervals as calibrated confidence bounds.

Quantile width is a useful selected uncertainty proxy here, but it mixes conditional noise
with model uncertainty and is not a pure epistemic estimate. The versioned method and
technique fields preserve that distinction. This result supports using quantile width in
the first bounded acquisition study while retaining explicit method provenance and
re-evaluating ensemble dispersion as the dataset grows.
