# v0.6 active-learning sample-efficiency study

This offline study compares uncertainty-active, seeded-random, and utility-only selection
on identical candidate and evaluation budgets for issue #116.

## Protocol

- ModelSurgeon study revision: `08dd7328c00a076db411d00b0319465dda471ad0`
- Dataset/model/split: the v0.5 3,000-mask SmolLM2-135M campaign and component-held-out
  2,400/300/300 train/validation/test split
- Seeds: 11, 23, 37, 53, 71
- Labeled-candidate budgets: 200, 400, 800, 1,200 for every strategy and seed
- Common seeded 200-example starting set within each seed
- Predictor: bounded LightGBM safe-mutation classifier, validation-only early stopping,
  fixed held-out test ROC-AUC
- Active acquisition: highest predictive Bernoulli uncertainty; utility-only: highest safe
  probability; random: fixed seeded order
- AULC: normalized trapezoidal area; 2,000 seeded bootstrap repetitions; 95% intervals
- Study JSON SHA-256: `a46082a055002dfc8b179711864c8b583310eb7ca519a70e60f012468de9e0dd`
- Learning-curve SVG SHA-256: `49d8de314bebd77e3ec52d70e9f79ea010e4b68638a5a94f4be666c7ed756e2a`

## Results

| Strategy | Mean AULC | 95% seed-bootstrap interval |
| --- | ---: | ---: |
| Active uncertainty | 0.5127 | [0.5019, 0.5234] |
| Seeded random | 0.5215 | [0.5106, 0.5353] |
| Utility-only | 0.5270 | [0.5100, 0.5440] |

## Negative result

Active uncertainty did not exceed the best equal-budget baseline mean AULC. Utility-only
was strongest on average, although all intervals overlap. The v0.5 classifier is close to
random ranking, and its uncertainty is therefore not a reliable acquisition signal in this
campaign. This result does not support a sample-efficiency claim for the initial active
policy; it establishes the reproducible baseline that later feature and policy work must
beat.

All 15 curves, 60 predictive-performance points, per-seed AULCs, intervals, seeds, and the
negative-result field are retained in the hashed JSON artifact. The SVG plots mean
predictive performance against experiments at the equal budget grid.
