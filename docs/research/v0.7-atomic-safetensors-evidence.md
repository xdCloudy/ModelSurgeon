# v0.7 atomic safetensors evidence

Windows-focused tests write both single-file and forced two-shard checkpoints through the same
filesystem used for development:

- The original safetensors shard remains byte-for-byte unchanged.
- Reloaded tensor names and shapes match the deterministic plan.
- Streamed staged payload SHA-256 values match the source tensor bytes.
- The sharded index maps every tensor to its verified shard and reports the exact total size.
- Configuration reloads from the published `config.json`.
- Injecting an I/O failure on the second shard leaves no destination or staging directory and
  does not change the source shard.

The focused proof passes alongside the existing non-overwriting checkpoint-destination tests.
