# v1.8 post-surgery LoRA: three seeds on the same 512-row test sample

## Result

Repeats the 128-update repair with seeds 42, 43, and 44, preserving the exact
training rows, validation rows, and 512-row shuffled test sample (sampling seed
2026) in every run. The model and dataset revisions, pruning, FP16 output,
training settings, and token-weighted validation selection are identical. The
test split was not used to choose checkpoints.

| Arm | Mean test token loss | Perplexity | Full artifact bytes |
| --- | ---: | ---: | ---: |
| Source FP16 | 3.45508 | 31.66080 | 272,437,465 |
| Pruned, no repair | 3.72457 | 41.45358 | 265,801,794 |
| Pruned, LoRA (mean of seeds) | 3.42256 | 30.64781 | 265,801,794 |

| LoRA seed | Test mean token loss | Loss recovered vs. no repair | Improvement vs. source | Selected step |
| ---: | ---: | ---: | ---: | ---: |
| 42 | 3.42003 | 0.30454 | 0.03505 | 127 |
| 43 | 3.42682 | 0.29776 | 0.02826 | 127 |
| 44 | 3.42082 | 0.30376 | 0.03426 | 127 |

The shared test sample contains 58,872 next-token targets. Mean recovery
relative to no repair was 0.30202 nats (sample standard deviation 0.00371), and
each seed scored below the source loss on this sample. Validation loss at step
127 was 3.12555, 3.12668, and 3.12528 for seeds 42, 43, and 44; step 128 was
slightly worse in every run and was rejected. This is evidence for the
validation selector on the declared sample, not a general claim that pruning
plus repair improves model quality.

All candidate artifacts reloaded successfully and were 2.44% smaller than the
source. Repair used 122,880 trainable parameters and 778,641,920 peak CUDA
allocated bytes; runtime was 444–452 seconds per seed on an RTX 3060. This study
does not measure inference-speed gains.

The runs share one model, pruning severity, and test sample. The three seeds
measure adapter initialization variability; they are not independent test
sets. Task-specific quality, other architectures, other pruning severities,
and inference throughput remain untested.

## Provenance and reproduction

The pinned Apache-2.0 SmolLM2-135M revision and pinned WikiText revision with
upstream CC-BY-SA-3.0/GFDL metadata are recorded in each report. All three
reports include the same split-file digest, test sampling seed, exact selected
rows, text hashes, model/runtime identities, and artifact manifests. Raw dataset
text is not included. The runner and deterministic row sampler were added in
the [512-row study](v1.8-lora-post-surgery-512test.md).

```powershell
uv sync --extra hf --extra research --locked
foreach ($seed in 42, 43, 44) {
  .venv\Scripts\python.exe tools/run_lora_post_surgery_study.py `
    --output "docs/research/v1.8-lora-post-surgery-128step-512test-seed$seed.json" `
    --remove-channels 64 --examples-per-split 64 `
    --test-examples-per-split 512 --test-sample-seed 2026 `
    --max-length 128 --rank 2 --steps 128 --seed $seed
}
```
