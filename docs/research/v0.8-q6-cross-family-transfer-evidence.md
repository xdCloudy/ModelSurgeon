# v0.8 Q6 cross-family transfer evidence

## Result

All three protocol topologies completed without feature-schema errors. Adding Qwen
to the Llama source improved regression transfer to the unseen SmolLM2-360M target,
while classification was already saturated. Holding Qwen out as an entire family
retained useful safe-channel ranking but did not transfer calibrated ΔPPL
regression.

| Protocol | Sources → target | AUC | precision@10 | calibration error | MAE | RMSE | R² |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| single family | SmolLM2-135M → SmolLM2-360M | 0.99735 | 1.000 | 0.28578 | 0.01502 | 0.01914 | 0.124 |
| multi family | SmolLM2-135M + Qwen2.5-0.5B → SmolLM2-360M | 1.00000 | 1.000 | 0.29201 | 0.01039 | 0.01275 | 0.611 |
| held-out family | SmolLM2-135M + SmolLM2-360M → Qwen2.5-0.5B | 0.85122 | 1.000 | 0.25011 | 0.01227 | 0.01438 | -1.246 |

Against single-family training on the identical SmolLM2-360M test partition,
multi-family training gained 0.00265 AUC, changed precision@10 by 0, reduced MAE
by 0.00463, and reduced RMSE by 0.00639. Calibration error worsened by 0.00624.
Thus multi-family training improved the continuous ΔPPL estimate in this fold, but
there is no meaningful evidence of a classification improvement because both
rankers are at or near the ceiling.

The held-out-family result is deliberately mixed. AUC 0.851 and precision@10 1.0
show that the ranker identified safe Qwen channels without any Qwen fitting rows.
The negative R² shows that its numeric ΔPPL predictions are worse than predicting
the held-out target mean. Cross-family ranking is supported here; cross-family
effect-size regression is not.

## Protocol and schema audit

- Single-family fitting uses only SmolLM2-135M's 409 train and 52 validation rows.
  Multi-family fitting adds Qwen's 409/52 rows. Both are evaluated on the same 51
  SmolLM2-360M test examples.
- Held-out-family fitting uses 818 train and 104 validation rows from the two Llama
  checkpoints, then evaluates 51 Qwen test examples. No Qwen row or fitted
  preprocessing statistic enters that model.
- Every result embeds its complete fitted preprocessing record. All datasets expose
  the same 33 numeric features, and inference produced no missing-feature failure.
- In the held-out-family path, `model_family=qwen` is intentionally absent from the
  fitted vocabulary and maps to the persisted `<unknown>` category. This tests the
  unknown-family schema path rather than silently adding target vocabulary.
- The evaluator validates each topology before training. Expected feature matrix or
  study errors are retained as structured failed outcomes with type and detail;
  all three outcomes in this run are `succeeded`, so there were no schema failures
  to report.

All protocols use the Q3 static-plus-activation-plus-gradient profile, ΔPPL <= 0.01
safe threshold, seed 42, split seed 43, 51-example component-held-out tests, and
1,000 grouped bootstrap repetitions for each metric report.

## Validity boundary

This matrix contains three checkpoints and two related decoder families; the
held-out-family protocol has one target family and one fold. The multi-family
comparison also changes training-row count, so it measures the practical value of
adding another family, not a row-count-controlled causal effect. The shared short
calibration corpus and single-channel-mask limitations from Q5 remain. Larger Gemma
and Mistral folds are still needed before generalizing the Qwen result to arbitrary
unseen architectures.
