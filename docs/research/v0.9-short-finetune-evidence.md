# v0.9 short fine-tuning repair evidence

## Result

A revision-pinned SmolLM2-135M candidate completed two seeded, selected-parameter
fine-tuning steps on one real layer-normalization vector. Only 576 parameters were
trainable. Validation loss against the no-repair candidate decreased from 6.19560
to 6.11164, so the best trained state was accepted with a content-derived child
checkpoint ID.

The selected tensor SHA-256 changed from
`a23ea2fd5797215a9e3cb70d7b62bbe2ab24aed12f606fd51e8d5e2b79c780ff` to
`3d49d1d09e73da14a7ac7ea7c514cccdaabadc8a27de4542143d9715c770b3b3`.
This directly confirms that the accepted child retained the trained state rather
than restoring the candidate snapshot.

## Bounded protocol and resources

- Model: `HuggingFaceTB/SmolLM2-135M` at commit
  `93efa2f097d58c2a74874c7e644dbc9b0cee75a2`.
- Selected parameter: `model.layers.0.input_layernorm.weight`; learning rate
  0.001, two steps, seed 42, and 14 tokens.
- Training used FP32 on the RTX 3060. Peak allocated/reserved CUDA memory was
  576,446,464/578,813,952 bytes, peak RSS was 1,639,809,024 bytes, and measured
  repair wall time was 0.9433 seconds.
- The implementation also tests exact pre-repair restoration after validation
  overfit rejection, wall-budget exhaustion, and trainable-parameter preflight
  failure.

## Validity boundary

This smoke run proves bounded selected-parameter mechanics, no-repair validation,
best-state retention, output lineage, resource capture, and real-model execution.
It does not establish downstream generalization or comparative repair benefit.
Those claims belong to the automated iterative study with held-out evaluation and
no-repair, repair, and one-shot baselines.
