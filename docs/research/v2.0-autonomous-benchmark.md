# v2.0 autonomous benchmark status

The v2.0 benchmark is a preregistered, fail-closed publication contract. The
repository contains the protocol and evidence validators, not a live campaign.
No model weights, held-out datasets, benchmark measurements, competitiveness
claims, or signed reference artifacts are published by this boundary.

The machine-readable protocol in
[`docs/design/v2-benchmark-publication.md`](../design/v2-benchmark-publication.md)
requires exact model and dataset revisions, licenses, multiple families and
sizes, equal budgets, at least three seeds, repeated measurements, complete
artifact lineage, and an independent audit/replay before a claim can publish.
Missing, negative, unsupported, failed, and unknown cells remain visible and
cannot be inferred as successes.

This status report is intentionally narrow: it documents what is implemented
and what remains unmeasured. A future campaign must add licensed inputs and
content-addressed evidence under the release record in
[`v2.0-autonomous-optimizer-release-v1.json`](v2.0-autonomous-optimizer-release-v1.json).
