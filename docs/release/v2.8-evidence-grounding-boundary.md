# v2.8 evidence-grounding boundary

The v2.8 evidence-factuality study closes a bounded evaluation gap. It measures whether claims emitted from canonical conversational evidence preserve source identity, distinguish measured values from predictions, retain negative and inconclusive outcomes, disclose uncertainty, and remain deterministic.

The release boundary is the typed `EvidenceSnapshot` → `EvidenceQuery` → claim-renderer path. Provider text, transcript text, and free-form narrative are not evidence. The unconstrained-text comparison is a retained negative control and is never a shippable explanation authority.

The checked-in protocol has fixed fixtures and held-out narratives, three replay seeds, fixed CPU/output bounds, strict thresholds, deterministic result IDs, and fail-closed handling for critical escapes. Failed and inconclusive cells remain in the canonical run record. The decision is limited to the checked-in corpus and does not make claims about live providers or broad language-model factuality.
