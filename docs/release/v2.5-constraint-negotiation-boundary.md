# ModelSurgeon v2.5 constraint-negotiation release boundary

Status: the bounded v2.5 milestone is verified by the
[machine-readable release record](../research/v2.5-constraint-negotiation-release-v1.json).
It closes the control-plane evidence boundary for measured infeasibility,
measured Pareto alternatives, and explicit objective amendments. It does not
provide automatic constraint relaxation, general language negotiation, or live
model-quality evidence.

## Frozen boundary

- Infeasibility is a read-only explanation over a canonical evidence archive.
  A hard constraint is evaluated as declared; no threshold, baseline, model
  identity, or evidence status is invented or weakened.
- Pareto alternatives are measured-only projections from the same archive.
  Unsupported, predicted, failed, unknown, inconclusive, rejected, and
  rolled-back evidence remains retained context and cannot become a frontier
  point without a new measurement.
- An objective amendment is an append-only record. It retains the original
  contract, source-model identity, approval scope, evidence archive,
  deterministic diff, and lifecycle history. A material approved amendment
  creates a new spec/campaign identity; the original remains unchanged.
- Approval follows the v2.0 boundary: execution approval is required, the
  exact visible diff is in scope, approval expiry is enforced, and stale
  replay fails closed. Direct Python APIs and the deterministic engine remain
  the execution authority; provider output and prediction are not evidence.
- The decision-quality protocol compares refusal-only, measured-Pareto, and
  prediction-only policies. Prediction-only results are retained as a
  negative control and are never shippable.

## Evidence and decision

The versioned protocol replays four typed fixture scenarios across three seeds
and a fixed four-evaluation campaign trace, retaining 36 policy/seed cells.
The measured-Pareto policy preserves every hard constraint, grounds every
presented alternative in measured evidence, traces every amendment, recovers
each expected feasible target, and has no misleading alternative claims. The
prediction-only control has a misleading-claim rate of 1.0 in its predicted
cells and remains permanently non-shippable. Negative and inconclusive cells
stay in the denominator.

This is a bounded, offline fixture study. It does not claim live HF/GGUF
quality, deployment compatibility, fluent preference elicitation, hostile
process containment, or automatic relaxation. Unsupported, unknown, failed,
predicted-only, and inconclusive outcomes are explicit release outcomes, not
silently converted into success.

## Reproduction and acceptance

From the repository root:

```text
uv run python tools/run_negotiation_quality_study.py
uv run python tools/run_negotiation_quality_study.py --json
uv run python tools/audit_v25_negotiation_quality.py
uv run python tools/audit_v25_constraint_negotiation_release.py
```

The acceptance tests cover the end-to-end fixture replay, direct explanation
and Pareto grounding, immutable amendment history, v2.0 approval boundaries,
retained terminal outcomes, deterministic IDs, documentation paths, and
duplicate-scope review. The exact dependency commits, budgets, run ID,
metrics, known skips, and quality-gate record are frozen in the release JSON.
